# Antigravity

Octapowers is installed globally for Antigravity by copying each skill to `~/.gemini/config/skills/<skill-name>/` and maintaining the router instruction in `~/.gemini/GEMINI.md`.

Antigravity indexes skill metadata and loads the full `SKILL.md` when relevant. It may request activation consent. A user can invoke a skill explicitly with `/<skill-name>`; use `/skills` to inspect discovered skills.

Use Antigravity's native tools and permission prompts. Do not assume Codex or Claude Code tool names, plugin commands, background-process behavior, or sandbox controls exist.
