# Codebuff / Freebuff

The global installer copies Octapowers skills to `~/.agents/skills/` and adds the router instruction to the home knowledge file Codebuff reads. Codebuff discovers the skills there and can load each `SKILL.md` through its native `skill` tool or `/skill:<name>` command.

Use Codebuff's native tools and permissions. Do not assume Codex or Claude Code plugin commands, hooks, or subagent APIs are available.
