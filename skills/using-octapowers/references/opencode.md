# OpenCode

The global installer copies Octapowers skills to `~/.agents/skills/` and adds the router instruction to `~/.config/opencode/AGENTS.md`. OpenCode discovers the skills there and loads each `SKILL.md` through its native `skill` tool when needed.

Use OpenCode's native tools and permissions. Do not assume Codex or Claude Code plugin commands, hooks, or subagent APIs are available.
